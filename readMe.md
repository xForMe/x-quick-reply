# X 快速回复 Chrome 插件

在当前 X 帖子回复弹窗或私信会话中生成候选回复，由阿里云百炼选择，再回填到输入框，供你检查后手动发送。

**当前版本：0.3.0，开发预览。** 2026-10-17 已通过 61 项前端和 25 项后端测试。整体提示词已用实际 gpt-6-luna 和百炼在合成样本中验证；真实 Chrome/X 编辑器回填仍待验收，有限样本不保证回复质量。

0.3.0 新增可编辑的“整体回复提示词”，默认按用户选择采用轻松幽默、日常聊天的口吻。生成与百炼筛选共用同一份偏好和事实/质量规则；避免套话、硬追问、强行鼓励及捏造经历，严肃情境不强求笑点。旧版本已有语言/格式提示，本次补充的是编辑标准和用户风格。提示词不能替代模型能力，也不能补足图片、作者关系或未读取的上下文。

0.2.8 调整回填：富文本框只交给编辑器处理一次粘贴，核验成功后记录插件草稿；选择其他候选，再点“回填输入框”可替换未经手动修改的插件草稿，同一候选重复点击不再次写入。你手动修改后会停止替换；初始已有草稿仍不覆盖。粘贴未被接收或核验失败时明确报错，不重试、不改用其他写入方式。

0.2.7 修正“仅允许当前 X 会话调用”：后台查询发送方标签页的当前地址，避免从首页经站内导航打开回复时把来源文档旧地址当作当前路由。仍校验本插件身份、X 域名、顶层标签页及当前回复/私信路由；不同失败原因分别显示。生成后若已离开页面，停止后续决策。此次只需重新加载扩展并刷新 X，无需重启网关。

**开发期间验证过的生成模型：gpt-6-luna；克隆后需自行配置。** 已按用户要求切换、重启网关并通过本机 HTTP 串联验证：中文合成帖总计 3.43 秒、英文合成帖 2.40 秒，各生成 3 条对应语言候选并由百炼选择。只切换生成模型时不需重新加载扩展；更新扩展代码时需按下文重新加载并刷新 X 页面。决策仍为 decision-model-preview。

0.2.6 将 Extension context invalidated 明确显示为“插件连接已失效。请刷新 X 页面，再重新打开回复弹窗并生成”。这说明当前页面的旧脚本与扩展连接已作废，无法用旧连接继续请求；不会自动重试或切换模型。重新加载扩展后，回到 X 按 F5，再打开原帖的回复弹窗。

0.2.5 回复语言跟随目标帖子正文：中文帖回复中文、英文帖回复英文，混合语言按主要语言并保留专有名词。生成和决策均使用此规则，不读取浏览器或 X 界面语言；针对明显的中英文文字体系错配，网关额外检查并停止整次请求，不只依赖模型判断。其他语言及复杂混合文本的识别仍由模型完成，不能保证每条判断正确。升级时须重启网关并重新加载扩展，两端统一使用 language=auto。

0.2.4 根据用户诊断修正无帖子链接的回复预览：不再强制从弹窗中提取帖子 ID，改为绑定当前弹窗、目标正文节点和输入框。仅有一个可见回复框时忽略隐藏副本；正文、链接、目标节点、弹窗、输入框或草稿变化后停止旧结果回填。仍只读取当前弹窗，不读取背景帖子。读取仍失败时，点面板“复制排查信息”并粘贴反馈；仅复制节点类型、容器层级及计数，不包含正文、草稿、帖子 ID、网址或凭据。

**面板已经出现时**：点击面板内蓝色“生成并填入回复”，等待生成，再检查 X 输入框。点击 X 输入框本身不会触发生成；等待中按钮显示“生成中，请稍候…”。

升级到 0.3.0：先自行保存需要保留的草稿；重启 Python 网关以加载共同回复规则，在扩展管理页重新加载插件并确认 **0.3.0**，回到 X 按 F5 后重新打开回复弹窗。打开“扩展设置”即可编辑整体提示词并保存，下次生成生效。协议已改为 quick-reply.v2，旧网关/扩展混用会明确报错；旧版重复草稿仍需你手动处理。

从 0.1.0 升级还需重启 Python 网关。0.1.0 仅支持私信且无图标入口；0.2.0 虽补充公开回复，但脚本初始化和异常提示仍存在缺陷。0.2.1 不再用 HTML 字符串构建面板，兼容禁止这类写入的环境，且不把残留面板节点当作已连接证据。

## 1. 准备环境

- Chrome 浏览器，已登录 X。
- Python 3.10 或更高版本。网关只使用 Python 标准库，无需安装第三方依赖。
- 可用的 OpenAI 兼容生成服务，以及阿里云百炼决策模型权限。

首次使用：克隆仓库并进入目录，将 `.env.example` 复制为 `.env`，填写第 6 节中的生成服务与百炼配置，再启动网关。已有 `.env` 时不要覆盖。

```powershell
git clone https://github.com/xForMe/x-quick-reply.git
cd x-quick-reply
Copy-Item .env.example .env
```

`.env` 仅保留在本地，已由仓库根目录 `.gitignore` 排除；提交的 `.env.example` 只有配置项与空白密钥。

## 2. 启动本地网关

在 PowerShell 中执行：

```powershell
python gateway.py
```

出现以下地址即表示服务已启动：

```text
Quick Reply gateway: http://127.0.0.1:8787
```

保持窗口运行。关闭窗口或按 `Ctrl+C` 会停止服务；每次使用插件前需要启动它。配置从工具目录读取，不受 PowerShell 当前目录影响。

只保留一个网关实例；0.2.5 禁止多个进程同时监听同一端口。若启动提示端口不可用，先停止旧窗口中的服务，再启动新版，避免旧代码继续接收请求。

## 3. 加载 Chrome 插件

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择以下目录，选目录而非某个文件：

```text
<仓库目录>\extension
```

只加载 `extension` 子目录。工具根目录包含 Python 网关、`.env` 和缓存，不作为 Chrome 扩展目录。

加载后应看到 **X 快速回复（预览）**，版本 **0.3.0**。工具栏图标点击后应出现带“打开快速回复面板”和“扩展设置”的弹窗。

## 4. 保存插件设置

在扩展页找到插件，点击“详细信息”→“扩展程序选项”，设置并保存：

| 设置 | 填写内容 |
| --- | --- |
| 本地网关 URL | `http://127.0.0.1:8787` |
| 默认语气 | 自然、简洁、礼貌或专业 |
| 候选数量 | 2–5，默认 3 |
| 整体回复提示词 | 默认轻松幽默；可编辑语气、接话方式和禁用表达，1–3000 字符，生成和筛选共用 |

点击“恢复默认提示词”只修改文本框，仍需点击保存；空白或超长不保存、不自动替换。自定义提示词保存在 Chrome 本地扩展设置，并会随当前上下文发送给已配置的生成与决策服务，别填写密钥或隐私。共同事实和质量规则在 [reply-policy.md](prompts/reply-policy.md)，默认可编辑风格在 [settings.js](extension/src/settings.js)。

若更改网关端口，插件中的端口也要一致。模型密钥填写在本地网关配置中，不填写到扩展选项。

## 5. 生成与回填回复

1. **回复公开帖子**：先打开原帖详情页，刷新一次，然后点击该帖的回复按钮。弹窗应同时显示原帖与“Post your reply / 发布你的回复”输入框。不要直接访问或刷新 `/compose/post` 来代替打开目标帖的回复弹窗。
2. **回复私信**：打开具体会话，路径形如 `/messages/<会话ID>` 或 `/i/chat/<会话ID>`，首次加载或更新插件后刷新页面。
3. 保持输入框为空，在右下角“快速回复”面板点击蓝色“生成并填入回复”。面板关闭后，可点工具栏插件图标→“打开快速回复面板”。
4. 插件读取当前回复目标，生成多个候选，再请求百炼选择。
5. 有合适候选时自动尝试回填；你检查内容后，手动点击 X 的发送按钮。

公开回复只读取当前弹窗中唯一目标帖的可见正文，不读取背景信息流；正文需非空且不超过 800 字符，候选回复不超过 280 字符。不能可靠识别目标、纯图片、多正文、引用帖和普通发帖框会报错停止；不支持帖子详情页的内联回复输入框。

私信处理最近最多 20 条可见消息，每条最多 800 字符，总计最多 8,000 字符。无法确定当前会话边界时停止；不能识别说话人时保留未知标记，不会假定全部消息来自对方。

生成期间请保持当前会话和草稿不变。切换会话、收到新消息、修改草稿或编辑框变化后，旧结果会停止回填；需要重新生成。初始输入框已有草稿时不会覆盖。成功回填后，可点另一条候选再点“回填输入框”，替换插件刚填入且未经手动修改的内容；相同候选重复回填不会追加。核验期间按钮暂时禁用。百炼拒选时会提示人工起草。

页面显示的“选择置信度”来自决策模型，不能当作回复正确率。当前仅针对 X 的帖子回复弹窗和私信，不支持其他聊天网站。

## 6. 模型配置项

配置保存在本目录 `.env`，格式参考 `.env.example`。**已有配置时直接修改对应项，不要用示例文件覆盖。** 不引用其他工具的配置文件。

| 配置项 | 用途 |
| --- | --- |
| `LLM_BASE_URL` | 生成服务的 OpenAI 兼容 Base URL，包含版本路径，例如 `/v1`；不含 `/chat/completions` |
| `LLM_MODEL` | 生成服务实际支持的模型名 |
| `LLM_API_KEY` | 生成服务密钥 |
| `LLM_JSON_MODE` | 默认 `false`；服务明确支持 `response_format=json_object` 时可设为 `true` |
| `DECISION_PROVIDER` | 普通百炼填写 `bailian`；Token Plan 填写 `bailian-token-plan` |
| `BAILIAN_SYSTEMONE_URL` | 普通百炼完整地址，包含业务空间 ID、地域及 `/compatible-mode/v1/systemone` |
| `DASHSCOPE_API_KEY` | 普通百炼 API 密钥 |
| `BAILIAN_TOKEN_PLAN_API_KEY` | 仅 Token Plan 使用的专用密钥，套餐地址由程序固定 |
| `MODEL_TIMEOUT_SECONDS` | 每次上游请求的超时秒数，默认 25 |
| `QUICK_REPLY_PORT` | 本地服务端口，默认 8787 |

决策模型固定为 `decision-model-preview`。进程环境变量优先于 `.env`；修改配置后重启网关。

2026-10-17 同一服务的少量合成帖子对比中，每次生成 3 候选，当时配置的 `gpt-6.1-sol` 平均约 4.9 秒，`gpt-6-luna` 约 2.4 秒，`gpt-5.6-luna` 约 10.0 秒；百炼决策约 0.3 秒。此为中英各一次样本，不保证长期延迟或质量。选型对比时未修改生产配置；随后经用户明确要求，已切换为 `gpt-6-luna` 并验证，最新结果见本文开头。以后修改 `LLM_MODEL` 须重启网关，扩展不会在失败时自动换模型。

## 7. 常见问题

| 现象或提示 | 处理方法 |
| --- | --- |
| 回复重复、自动填入后无法切换候选 | 更新到 0.3.0，保存草稿后刷新 X，手动处理旧版重复文本，再在空框生成；新版支持替换未修改的插件草稿 |
| 当前编辑器未接收粘贴事件 / 回填核验失败 | 保留完整错误反馈；本次停止，不再尝试其他写入，不自动删除已有内容 |
| 加载时报 `__pycache__` 名称保留 | 选择 `quick-reply\extension` 子目录重新加载；不要选择工具根目录 |
| 工具栏图标点击没有操作弹窗 | 扩展管理页重新加载，确认版本为 0.3.0；弹窗应显示版本和打开面板按钮 |
| 仅允许当前 X 会话调用 | 更新到 0.3.0 并刷新 X；旧后台可能误用导航前的来源地址。新版查询当前标签页并分别显示具体校验错误 |
| Extension context invalidated / 插件连接已失效 | 回到 X 网页按 F5，再打开原帖回复弹窗；只重新加载扩展不会刷新现有页面中的旧脚本 |
| 请打开唯一的帖子回复弹窗 | 更新到 0.3.0；旧版错误地要求全页面只有一个弹窗容器。新版按唯一可见回复框确定边界 |
| 目标帖子 ID 不唯一或无法识别 | 更新到 0.3.0；回复预览可能没有帖子链接，新版使用当前弹窗和正文节点绑定回复目标 |
| 中文帖子生成英文回复 | 更新到 0.3.0，并确保运行新版网关；新版按目标正文语言生成和选择，不使用 X 界面语言 |
| 请求 schemaVersion 无效 / 生成接口协议版本无效 | 网关和扩展须一起更新到 0.3.0，重启网关并重新加载扩展 |
| replyPrompt 无效 / 整体回复提示词为空 | 在扩展设置填写 1–3000 字符并保存，不会自动替换成其他文案 |
| language 必须为 auto | 网关和扩展版本不一致；同步更新并重新加载扩展 |
| 新版仍读取失败 | 点击面板“复制排查信息”，粘贴反馈；复制失败会明确报错，不自动上传页面或正文 |
| 旧提示“当前页面未连接扩展” | 更新到 0.2.1 后点“打开快速回复面板”；新版先初始化，再连接，不再统一显示该模糊提示 |
| 注入页面脚本 / 加载面板样式 / 连接页面脚本失败 | 保留完整错误。各阶段失败即停止，不自动重试；权限、初始化和消息端口错误会分别显示，不能仅凭连接失败断定模型不可用 |
| 页面没有面板 | 回原帖详情页刷新，再点原帖回复按钮；也可点击插件图标打开面板。私信则刷新具体会话页 |
| 读取失败：无法确定回复目标或输入框 | 本版要求唯一可见回复框，以及同一弹窗内位于它之前的唯一目标正文。保留具体错误用于排查，不会改用背景帖子兜底 |
| 网关连接失败 | 确认 PowerShell 中网关仍在运行，并核对扩展设置的端口 |
| 缺少配置项 | 在本目录 `.env` 填写提示的字段，重启网关 |
| HTTP 401 / 403 | 核对失败服务的密钥、模型权限和业务空间；普通百炼与 Token Plan 凭据不可混用 |
| HTTP 402 / 429 | 核对失败服务的额度和限流；程序不自动重试或切换身份 |
| 候选 JSON 无效或输出被截断 | 检查生成模型是否按契约返回完整纯 JSON；Markdown 包裹也会被拒绝 |
| 没有读到消息或找不到输入框 | 确认会话内容已加载，保留具体报错用于页面适配排查 |
| 会话或草稿已变化 | 检查当前会话和草稿，重新生成 |
| 百炼未选择合适回复 | 人工起草，不会自动填入替代文案 |

请求失败会停止当前依赖链，明确报错，不使用 Mock、固定答案、缓存旧结果、部分结果或其他模型兜底。

## 8. 更新、停用与隐私

- 修改扩展代码后，在 `chrome://extensions` 点击插件的“重新加载”，再刷新 X 页面。
- 修改网关代码或 `.env` 后，停止并重新启动网关。
- 停用时在扩展页关闭插件，再停止网关。已有草稿由你自行处理。
- 生成服务和百炼都会收到所选对话内容；本地网关不等于本地模型推理。
- 网关仅监听本机，不保存聊天正文或请求日志；模型密钥不要提交仓库或贴入聊天。

详细说明见 [需求](doc/需求.md)、[技术](doc/技术.md)、[测试证据](doc/测试.md)和[部署](doc/部署.md)。

开发检查：在工具目录执行 `npm ci` 安装仅用于测试的 jsdom、React 17 和 Draft.js，再执行 `npm test`；后端执行 `python -X utf8 -m unittest discover -s tests -v`。网关和扩展运行不需要 Node.js 或这些测试依赖。

提示词实际样本见 [提示词样本验证](doc/提示词样本验证.md)。手动执行 `python -X utf8 tests/evaluate_prompts.py` 会真实调用配置服务并记录合成样本输出，首次失败即停止，无重试；不属于 `unittest` 自动化测试。
